L / N / H / 0 - how to read the following-word markers

Following-word effects: L lenition; N nasalization; H historical aspiration/gemination; 0 no regular L/N/H effect prescribed here. The marker belongs to the form before it and describes the next closely connected word, not a suffix. Effects need not be visible in spelling; phonological and syntactic restrictions still apply. Prepositional = the case often called dative. The vocative particle a itself lenites the noun; a marker at the end of the vocative phrase describes what follows the noun.

02 / FOCUS

The rule, clearly

为什么 echu 旁边会标 H？

问题不在今天的 -u，而在它过去丢失的 -s。

① 从不同语言倒推词尾，不罗列整套变格：

为什么 echu 旁边会标 H ？
语言 “马”的 ACC PL 对重建有用的信息
Latin equōs 保留 -s，鼻音已经消失
Sanskrit aśvān 保留 -n，末尾 -s 已消失
Old Irish echu 原来的 -ns 均不再写出

三者是同源语言的平行结果，不是「拉丁语 → 梵语 → 爱尔兰语」的传递链。比较它们，才能重建古老的主题词干宾格复数词尾 *-ons。

② 名词本身的历史音变（简化表示）：

PIE             *-ons   (主题元音 -o- + ACC PL *-ns)
pre-Proto-Celt. *-ōns   (史前长元音阶段；简化表示)
Proto-Celtic    *-ūs    (词尾鼻音消失，*ō > *ū)
Old Irish        -u     (词末 -s 消失；但连读可能有痕迹)

以上是词末单独发音的发展；s 在紧跟另一词时可能经历不同的变化。*-ōns 的中间阶段及绝对年代属于重建，非手稿直接记录。

③ 名词后的连读又是一条独立的变化：

较早阶段       *...-s # V-...   (# = 词界；V = 元音)
元音间弱化     *...-h # V-...
重新划分词界   *...  # hV-...

因此，理论上同一个 *-s 可以同时解释两件事：名词孤立形式中已经没有 -s，但紧接的元音开头的词可能留下 h-。辅音前则更可能体现为阻止弱化／早期的辅音延长，而非在辅音前机械添加一个 h。

关键限定：上面的第③步是可解释 H 的史前机制；不能直接当作 echu 在古爱尔兰语手稿中确实触发 h- 的证据。

PIE → Celtic → Old Irish

Historical analysis and sources (tap to collapse)

哪些能证明，哪些只是推断？

  • 有古文献例证的是冠词或小品词之后的现象。 Thurneysen, A Grammar of Old Irish §§240–241 记有 inna-mmaccu（Ml. 104d5，‘the sons’，ACC PL）。这里首辅音的加倍发生在 冠词 inna → 名词 *maccu*** 的边界；它不能证明 **名词 maccu → 下一个形容词 也有同样效果。
  • 传统规则： Thurneysen 以及 UT Austin Old Irish Online, §6.3 将 ACC PL 归在受旧词尾 -s 影响的一组形式中；教学格表因此常写 ACC PL H。
  • 更严格的证据判断： David Stifter, “The rise of gemination in Celtic” (2023), §8.1，指出古爱尔兰语中 h- 的清楚语法环境主要是前附小品词；普通阳性、阴性名词的 ACC PL 触发 h-，尚无直接书面证据，只能推测。 这也是为什么本课将 H 写作「传统推定」，而非「已证实」。
  • 另一个有助于理解的对照： ACC SG 的旧词尾 *-om > *-on 可以解释为何单数 ech（ACC）虽不写 -n，后接词仍与 N nasalisation 关联。N 与假设中的 H 是同一种历史逻辑（丢失的词尾留下连读痕迹），但证据强度不同。

今天只要记住一句： 「古爱尔兰语 ACC PL 的 H 来自重建的旧 -s 连读效果，而不是现代可见的 -u；对普通名词而言，实际是否保留这一效果仍有证据限制。」

参考： Stifter (2006), §§6.4–6.6；Thurneysen, A Grammar of Old Irish, §§240–241、286（在线文本）；Stifter (2023), §8.1（研究论文）；UT Austin, §6.3。
