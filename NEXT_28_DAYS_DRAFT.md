# Proposed study days 029–056 (draft)

> **How this was built (v0.2).** Section numbers and the "anchor" notes below come from the full text of Stifter (2006) (Lessons 14–24, printed pp. 74–121), which I checked section by section. **The draft still lists topics only, not paradigms or forms**: each lesson must be authored from the printed page. Same type codes as `FIRST_28_DAYS.md`: N nominal, S syntax/article/prepositions, V verb, T test/reading/review, H historical-comparative.

Design choices

* Same weekly rhythm as the first 28 days: five new items, one short check, one historical/comparative day; one cumulative review each week (Days 035, 042, 049, 056).
* One active target per day; ~10–15 minutes.
* Order follows Stifter's lessons 14–24 so every day only needs grammar already met.
* The "random review" fallback on the home page still applies on any day without an authored lesson.
