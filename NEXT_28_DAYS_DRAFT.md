# Proposed study days 029–056 (draft)

> **How this was built.** The section numbers below come from the **table of contents** of Stifter (2006) in your Drive copy. I could read the book's text only up to p. 68, so **this draft lists topics and section numbers only. It does not list paradigms or forms**; each lesson must be authored from the printed page (see `REVIEW_FIRST_28_DAYS.md`, §5). Same type codes as `FIRST_28_DAYS.md`: N nominal, S syntax/article/prepositions, V verb, T test/reading/review, H historical-comparative.

Design choices

* Same weekly rhythm as the first 28 days: five new items, one short check, one historical/comparative day; one cumulative review each week (Days 035, 042, 049, 056).
* One active target per day; ~10–15 minutes.
* Order follows Stifter's lessons 14–24 so every day only needs grammar already met.
* The "random review" fallback on the home page still applies on any day without an authored lesson.
