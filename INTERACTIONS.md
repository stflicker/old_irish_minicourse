# Interaction and record commands

## Browser

- `Hide forms` / `Show forms`: recall practice.
- Answer buttons: instant correctness feedback. Try again after errors.
- Hints and historical comparisons: collapsed by default.
- `Mark complete`: records a correct attempt **locally**.
- `Copy record`: use the Markdown row in chat or to update `PROGRESS.md` elsewhere.
- `Download PROGRESS.md`: aggregate locally completed days into a portable document.

Browser buttons do **not** connect to GitHub. A live update of repository progress after a quiz requires an authenticated app/endpoint; v0.4 avoids adding passwords or private GitHub tokens to the static HTML.

## Chat

Use minimal feedback like `D001 done; 12m; difficulty 2/5; genitive was tricky`.

- `check` to grade form interpretation.
- `hint`, `again`, `parse`, `compare` for more on the present topic.
- `catch up` for missed dates.
- `export progress` for a current learner-feedback-based record, not a claim that downloaded copies are synced.

Use the same lesson IDs and six record columns everywhere. Calendar push is not the same as completion.
